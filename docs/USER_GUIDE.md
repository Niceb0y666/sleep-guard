# 休眠哨兵使用指南

休眠哨兵（Sleep Guard）在菜单栏显示 Mac 的系统级 `SleepDisabled` 设置，并在检测到休眠禁用时提醒你。监测本身不需要管理员权限。

`SleepDisabled = 0` 只说明这个禁用开关已关闭，不表示电脑已经进入睡眠，也不能保证外接显示器、应用活动等情况下合盖一定会睡眠。应用不判断是谁更改了设置。

## 安装与首次启动

需要 macOS 13 或更新版本。源码构建方法见[项目说明](../README.md)。构建产物默认位于 `dist/休眠哨兵.app`；当前已记录的本机验证使用 Apple Silicon，其他架构的验证范围见[验证记录](VALIDATION.md)。

1. 将 `休眠哨兵.app` 放入“应用程序”文件夹，从 Finder 双击打开。
2. 首次运行会打开“状态与设置”窗口。等待首次检测完成，查看系统状态和最近检测时间。
3. 点击“启用通知”，在 macOS 弹窗中选择是否允许通知。
4. 点击“测试提醒”，检查实际通知显示。首次直接点击“测试提醒”时，应用会先请求授权，取得授权后继续提交测试通知。
5. 如需每次登录后持续监测，勾选“登录时启动”。

应用是菜单栏工具，通常不会显示 Dock 图标。关闭状态窗口后，监测继续运行。双击应用或从菜单栏选择“状态与设置…”可以再次打开窗口。

## 看懂状态

| 显示 | 设置含义 | 建议 |
| --- | --- | --- |
| 绿色月亮，“系统允许休眠” | 已明确读到 `SleepDisabled = 0` | 这个全局禁用开关已关闭；实际睡眠行为仍需另行观察 |
| 橙色月亮和“休眠禁用” | 已明确读到 `SleepDisabled = 1` | 准备收起电脑时，先检查是否需要恢复休眠 |
| 灰色问号和“未知” | 读取失败、超时或输出无法识别 | 打开状态窗口查看原因，点击“马上检测” |
| “正在检测” | 尚未取得首次结果 | 等待读取完成 |

应用大约每 10 秒读取一次设置；定时器可能受系统调度影响。Mac 唤醒后、应用重新成为活动应用时、菜单打开时也会触发读取。睡眠期间应用不能按固定间隔执行检查。

“最近检测”是这次读取完成的时间，失败的读取也会更新时间。“首次发现禁用”是本次运行中检测到该禁用事件的时间，不是系统开关真正被修改的时间。状态记录仅保存本次运行最近五条已知状态变化，退出后清空。

## 配置提醒

“休眠禁用时通知我”控制自动通知。关闭它后，菜单栏仍然显示检测状态。

应用在首次取得明确的禁用结果时尝试提醒；启动时已经禁用的情况也包括在内。持续禁用默认每 30 分钟提醒，可以改成：

- 只在首次发现时；
- 每 5 分钟；
- 每 15 分钟；
- 每 30 分钟；
- 每 60 分钟。

提醒间隔在当前禁用事件的一次成功提交之后计算。成功提交表示 macOS 接收了通知请求，不保证横幅、声音或通知中心条目已被用户看到。应用退出后，提醒时间不保留；重新运行时会重新判断是否需要首次提醒。

若通知提交失败，状态窗口显示错误，自动提醒约 60 秒后再尝试；前提是应用仍在运行、当前读数仍为禁用、提醒已开启且通知权限允许。读取结果为“未知”时，不会根据旧读数继续提交新的禁用提醒。

### 通知权限

通知尚未授权时，点击“启用通知”。授权被拒绝后，点击“通知设置…”前往系统设置，找到休眠哨兵并调整权限；再次请求通常不会重新出现首次授权弹窗。

“系统通知已获授权”不等于横幅一定显示。通知样式、声音设置和专注模式仍会影响呈现。“系统通知为静默投递”表示授权状态为临时静默授权。无论通知是否获授权，禁用读数仍会在菜单栏提示。

“测试提醒”用于检查通知通道，不会更改系统休眠设置，也不会改变重复提醒间隔。它属于手动操作，即使自动提醒已暂停，仍可使用。

## 登录时启动

建议先把应用放在稳定的位置，再开启“登录时启动”。

- 勾选成功并显示已启用：系统已登记该应用为登录项。仍需在下一次实际登录后确认菜单栏出现休眠哨兵。
- 提示“启动项等待批准”：前往系统设置 → 通用 → 登录项，按系统提示批准。
- 注册报错：查看错误文本，确认应用路径是否仍有效，然后重试。

应用不在首次运行时自动替你启用登录启动。对于已经启用的登录项，可以取消勾选；待批准的登录项可以从系统设置中管理。

## 恢复系统休眠

从菜单栏选择“恢复休眠说明…”，点击“复制命令”。如果你希望关闭系统级休眠禁用，在终端执行：

```bash
sudo pmset -a disablesleep 0
```

这条命令会修改系统电源设置，需要你在终端按提示输入 Mac 登录密码；输入时通常不显示字符。应用只提供说明和复制操作，不执行这条命令，也不接收密码。

执行后点击“马上检测”，确认状态更新。也可以独立读取：

```bash
pmset -g
```

如果开关后续再次变为禁用，休眠哨兵可以提醒你，但不能据此确认哪个应用或哪个人进行了修改。

## 退出与移除

菜单栏中的“退出休眠哨兵”会停止本次运行的监测。仅关闭状态窗口不会停止监测。

如不再使用，先取消登录启动或在系统设置中移除登录项，再退出应用并删除 `.app`。通知权限与偏好由 macOS 管理，删除应用不代表这些记录一定立即消失。

遇到启动、通知或读数问题时，查看[故障排查](TROUBLESHOOTING.md)。
